# Floret v3

Каноническая документация v3, примеры API, storage SPI и процедура миграции находятся в [README.md](README.md). Эта страница намеренно не дублирует примеры, чтобы не сохранять устаревшую поверхность API.

Модуль: `github.com/floegence/floret/v4`. Floret v3 является единственным источником истины для принятого жизненного цикла Agent. Он использует только `provider.Gateway`, хранит `runtime.Host` исключительно в composition root, самостоятельно назначает идентификаторы жизненного цикла и выдает узкие handles, привязанные к идентификаторам. Автоматической миграции и legacy decoder при запуске нет.
