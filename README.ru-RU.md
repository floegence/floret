# Floret v7

Каноническая документация v7, примеры API, storage SPI и процедура миграции находятся в [README.md](README.md). Эта страница намеренно не дублирует примеры, чтобы не сохранять устаревшую поверхность API.

Модуль: `github.com/floegence/floret/v7`. Floret v7 является единственным источником истины для принятого жизненного цикла Agent. Он использует только `provider.Gateway`, хранит `runtime.Host` в composition root и предоставляет типизированный `ThreadService`. `runtime.Open` автоматически переносит поддерживаемое доменное состояние Floret.
